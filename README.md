## Описание
Программа сервиса для заказа еды. Работает в командной строке (CLI), данные хранятся в текстовых файлах.

## Функции
- Просмотр меню из 10 блюд
- Добавление блюд в корзину
- Просмотр корзины с подсчетом суммы
- Бесплатная доставка при заказе от 600 рублей
- Выбор адреса доставки из списка
- Оформление заказа с подтверждением
- Сохранение истории заказов в файл
- - **Защита от некорректного ввода** (буквы не вызывают ошибок)

## Файлы программы

| Файл | Назначение |
|------|------------|
| main.py | Главный файл для запуска |
| menu_manager.py | Работа с меню |
| cart_manager.py | Работа с корзиной | 
| order_manager.py | Работа с заказами | 
| file_handlers.py | Работа с файлами | 
| constants.py | Константы | 
| menu.txt | Список блюд и цены | 
| addresses.txt | Список адресов доставки | 
| orders.txt | История заказов | 
| README.md | Документация |
